# The Specimen Review

A poetry journal for the STEM disciplines.

**Live site:** [thespecimenreview.org](https://thespecimenreview.org)

## About

The Specimen Review publishes poetry inspired by science, with each poem organized by the scientific discipline it engages with. The journal is a space where scientists, students, and writers can explore research, discovery, and the natural world through creative writing.

Founded in 2025 by Tessa Schauermann, who serves as editor-in-chief alongside a small team of editors and artists.

## Built With

- HTML
- CSS
- [Browser Sync](https://browsersync.io/) for live local preview

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/tpsparklez/specimen-review.git
   cd specimen-review
   ```
2. Install Browser Sync (requires [Node.js](https://nodejs.org/)):
   ```bash
   npm install -g browser-sync
   ```
3. Start a local server that reloads as you edit:
   ```bash
   browser-sync start --server --files "*.html, css/*.css"
   ```
